# Hot Dog Stand

## Description
This program creates a menu for Bratty Buns Hot Dog Stand.
It shows all 128 possible hot dog combinations using seven
different toppings and calculates the price for each one.

## Requirements
- Java JDK 21
- A terminal or PowerShell
- Git

## Usage
1. Download the project files.
2. Open a terminal in the project folder.
3. Compile the program using:
   javac HotDog.java
4. Run the program using:
   java -ea HotDog
5. The program will print all 128 hot dog combinations
   and their prices.
